# Endurance 5

Cette version d'endurance est encore en cours, mais contrairement aux dernières, j'ai utilisé des fichiers du type DXF (Drawing Exchange Format) pour faire le drone. Le format DXF est un format de fichier que j'ai découvert récemment et qui est utilisé pour de l'échange de données CAO, cela permet de transmettre facilement des arrêtes tout en ayant la possibilité d'avoir une compatibilité entre différents logiciels de CAO. Ce format de fichier est open source et il est souvent utilisé en architecture et en ingénierie. 
Pour faire ces fichiers, j'ai donc demandé à une IA de me les générer en respectant les paramètres que l'on avait précédemment définis ensemble. Après avoir téléchargé puis téléversé ces fichiers dans Onshape, j'ai créé les plans (décalés à des points précis par rapport au centre) pour y mettre les esquisses et les arêtes des fichiers DXF. Cela m'a par la suite donné ce qui apparaît dans les images ci-dessous. Par la suite, il ne me restera plus qu'à faire un lissage et à régler les problèmes qui pourraient survenir.
